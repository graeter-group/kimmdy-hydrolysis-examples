# Using KIMMDY to simulate competing reactions in peptides

And a collection of KIMMDY examples for hydrolysis to demonstrate the interplay between various kimmdy plugins.
This also includes tips for interactively stepping through KIMMDY to explore how it works under the hood.

## Setup

```bash
./setup.sh
```

## Run Simulations

[run.qmd](run.qmd)

## Analysing published simulations

Download `results.zip` from the [latest release](https://github.com/graeter-group/kimmdy-hydrolysis-examples/releases).

Extract assets:

```bash
./scripts/extract-assets.sh
./scripts/unzip-data.sh
```

Explore [thesis.qmd](thesis.qmd) to reproduce the plots.
